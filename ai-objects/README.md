# 🎯 AI Детектор объектов (COCO-SSD)

Камера телефона или видеофайл → ИИ находит **80 видов объектов** (люди, машины, автобусы, грузовики, животные, предметы) и считает их по видам. Всё работает прямо в браузере: видео никуда не отправляется.

🔗 **Открыть**: https://aw1rn.github.io/camera-kz/ai-objects/

## Возможности
- 📷 Задняя / 🤳 фронтальная камера, 🎞 видеофайл
- Рамки с русскими названиями и уверенностью ИИ
- Счётчик «Сейчас в кадре» по видам объектов
- Фильтр: люди / транспорт / животные / предметы
- Настройка уверенности и максимума объектов
- 📸 Снимки с рамками, скачивание по нажатию
- PWA: можно установить на телефон, после первой загрузки работает без интернета

## Состав
- `lib/tf.min.js` — TensorFlow.js 4.22 (Apache-2.0)
- `lib/coco-ssd.min.js` — @tensorflow-models/coco-ssd 2.2.3 (Apache-2.0)
- `model/` — веса COCO-SSD (~18 МБ)

## Локальный запуск
```bash
python -m http.server 8000
# открой http://localhost:8000
```
По `file://` камера не работает — нужен localhost или https.
