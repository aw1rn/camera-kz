# 🎥 AI Камера — Распознавание лиц

Веб-приложение с фронтальной и задней камерой и распознаванием лиц в реальном времени.

🔗 **Демо**: https://aw1rn.github.io/camera-kz/ai-camera/

## ✨ Возможности

- 🤳 Фронтальная и задняя камера
- 🔄 Переключение одной кнопкой
- 👤 Обнаружение нескольких лиц одновременно
- 📊 Определение возраста и пола (приблизительно)
- 🎯 68 точек лица (landmarks)
- 📸 Снимки с галереей
- 📈 Счётчик лиц и FPS
- 📲 PWA — установка на телефон
- ⚡ Офлайн-кэш через Service Worker

Всё обрабатывается прямо в браузере: видео никуда не отправляется.

## 🛠️ Технологии

- [face-api.js](https://github.com/vladmandic/face-api) (TensorFlow.js)
- MediaDevices API
- Canvas API
- Service Worker (PWA)

## 📱 Использование

1. Открой ссылку на телефоне или ПК
2. Разреши доступ к камере
3. Выбери камеру (фронт / задняя)
4. Смотри распознавание в реальном времени

## ⚠️ Требования

- **HTTPS** (GitHub Pages даёт автоматически)
- Современный браузер: Chrome, Safari, Firefox, Edge

## 🚀 Локальный запуск

```bash
python -m http.server 8000
# открой http://localhost:8000
```

⚠️ По file:// камера не работает — нужен localhost или https.
