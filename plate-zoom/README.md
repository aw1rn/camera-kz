# Plate Zoom — распознавание номеров с цифровым зумом

Работает с готовым видеопотоком (KazToll, RTSP, m3u8, видеофайл).

Конвейер обработки:

**поток → YOLO находит машины + ByteTrack (ID) → цифровой зум машины → поиск номера → зум пластины → OCR → проверка формата KZ → голосование по кадрам → SQLite**

## Установка

```bash
python -m venv venv
venv\Scripts\activate            # Windows  (Linux/Mac: source venv/bin/activate)
pip install -r requirements.txt
pip uninstall -y opencv-python   # ultralytics ставит обычный opencv, он конфликтует с contrib
pip install --force-reinstall opencv-contrib-python
```

## Запуск

```bash
# минимально (контурный поиск номера + бикубический зум)
python main.py --source "https://.../index.m3u8"

# рекомендуемо
python main.py --source "https://.../index.m3u8" --plate-weights plate.pt --sr-model FSRCNN_x4.pb
```

Управление в окне:

| Действие | Что делает |
|---|---|
| ЛКМ по машине | камера слежения: крупный план в правой панели |
| ПКМ | снять выбор |
| `+` / `-` | сильнее или слабее приближение |
| `Q` / `Esc` | выход |

Результаты сохраняются в `data/plates.db` (таблица `plates`), снимки номеров — в `data/plates/`.

## Как достать ссылку на поток KazToll

1. Открой страницу с камерой в Chrome.
2. Нажми F12 → вкладка **Network** → в фильтре введи `m3u8`.
3. Скопируй адрес и передай его в `--source`.

## Модель суперразрешения (цифровой зум)

Скачай `FSRCNN_x4.pb` (быстрая) или `ESPCN_x4.pb` из репозиториев
`Saafke/FSRCNN_Tensorflow` или `fannymonori/TF-ESPCN` на GitHub. Имя файла должно остаться вида `ИМЯ_xN.pb`.
`EDSR_x4.pb` даёт лучшее качество, но работает очень медленно на CPU.

## Детектор номеров (`plate.pt`)

Без него используется контурный поиск: он работает, но часто ошибается.
Чтобы получить свою модель:

1. Сделай 200–500 скриншотов машин с потока.
2. Размечай номера на roboflow.com (класс `plate`) и экспортируй в формате YOLOv8.
3. Обучи модель:
   ```bash
   yolo detect train data=data.yaml model=yolov8n.pt epochs=60 imgsz=640
   ```
4. Возьми `runs/detect/train/weights/best.pt` и передай его через `--plate-weights`.

## Полезные параметры

- `--device 0` — запуск на видеокарте NVIDIA
- `--ocr-every 3` — как часто читать номер у одной машины
- `--lock-hits 4` — после скольких одинаковых чтений номер записывается
- `--min-car-h 60` — машины меньше этой высоты (в пикселях) пропускаются: номер всё равно не прочитать

## Поддерживаемые форматы номеров

- `123 ABC 01`
- `123 AB 01` (регион 01–20)

Префикс `KZ` отбрасывается, путаница O↔0, B↔8, S↔5 исправляется по позиции символа.
