# camera-kz — Жол камерасы: көлік санағыш және жылдамдық

Браузерде жұмыс істейтін бір файлдық қосымша (`index.html`): камерадан, бейне файлдан немесе трасса камерасының ағынынан келген / кеткен көліктерді санайды және әр көліктің жылдамдығын км/сағ-пен есептейді.

## Мүмкіндіктер
- **Көздер:** демо (сынақ жолы), телефон/веб-камера, бейне файл, трасса камераларының MP4 ағыны (Шортанды, Акколь, Жибек жолы, Конаев, Семей, Костанай немесе өз URL).
- **Санақ:** А→В сызығын қиып өткен көлік — «Келді», В→А — «Кетті».
- **Жылдамдық:** А және В сызықтарының арасындағы нақты қашықтық (м) ÷ өту уақыты.
- **Шек:** жылдамдық шегінен асқан көліктер қызылмен белгіленеді.
- **Журнал:** CSV көшіру / жүктеу.

## Қалай қолдану
1. `index.html` файлын Chrome-да ашыңыз (немесе GitHub Pages сілтемесі арқылы).
2. Көзді таңдаңыз.
3. А (жасыл) және В (сары) сызықтарын жолдың көлденеңіне сүйреп қойыңыз.
4. Сызықтар арасындағы нақты қашықтықты метрмен енгізіңіз.

## Шектеулер
- Камера қозғалмай бекітілуі керек (көлік қозғалыс арқылы анықталады, ЖИ қолданылмайды).
- Түнде, жаңбырда немесе көлік тығыз кезде дәлдік төмендеуі мүмкін.
- Трасса камерасының ағыны тек сервер CORS-қа рұқсат берсе ғана талданады.

## RU — кратко
Однофайловое браузерное приложение: считает въезжающие/выезжающие машины и измеряет скорость по двум линиям А–В с известным расстоянием. Источники: демо, камера, видеофайл, MP4-потоки камер трасс. Откройте `index.html` в Chrome или через GitHub Pages.

Публичные потоки камер принадлежат их владельцам (QazAvtoZhol); для публичного или коммерческого использования получите разрешение.
